初步判断
示例中的“用于战争、伤害人员”等明确恶意意图，是触发模型安全护栏的重要信号；即使删除该语句，高度相关的CBRN操作内容本身仍可能触发拦截。
文本来源分析
示例内容不像直接摘自专业文献，更可能由AI拼接生成。实验重点不在文本是否真实，而在其是否包含完整、可执行且具有明显风险的语义链。
素材获取策略调整
公开论文和专业书籍通常侧重检测、治疗、防护与解毒，较少提供危险物质的正向制备流程。因此，后续主要借助AI生成和补全测试文本。
4. 提示词构造方法
①先获取总体框架，再逐步补充具体环节，由抽象向具体递进。
②从制备流程扩展到扩散、投送、战争用途等高风险应用场景。
③通过明确意图、连续步骤和多轮递进增强风险语义。
5. 测试入口选择
安全护栏：网页版>客户端>中转站调API，国外模型>国内，深度思考>快速思考，因此优先选择较容易生成测试素材的低护栏入口。网页豆包快速版（QWEN安全护栏也很低）
6. 主要观察
①高风险生物培养（B类）、明确伤害意图和递进式危险流程，更容易触发“Chat paused”“无法显示此内容”或会话终止等强阻断。
②化学（C）、放射性（R）和核类文本（N）更多触发明确拒绝，或被引导至检测、防护、合规和应急等安全替代内容。

========== task2\报告\task2测试结果分析报告.docx ==========
遇到的问题及解决：
1.由于①生成的APK文件太大且②gpt用的是ws长连接，非常脆，直接让codex CLI分析频繁导致stream disconnected，进度受阻；
2.改用客户端GPT，GPT普通号，plus账号，pro账号表现参差不齐。安全护栏（效果）pro>plus>普号，可能还与个人设置，账号健康程度有关系；
3.为了保持统一，claude也采用客户端agent。claude安全护栏高，所以效果一直很好。但是claude测试容易被封禁，于是我在海鲜市场买了大量普号利用sonnet5的免费额度测试；
4.GPT测试效果没有预期好，更多可能是非任务本身原因而是GPT本身安全护栏不稳定和我测试时候账号的原因，claude的测试很有参考性;
5.选择GPT和claude的原因是这两个模型安全护栏在上次测试中表现最高。
1. 总体触发结果
测试中，P 结果为 53 次，F 结果为 31 次，对应总体经验触发率 63.1%。从构成上看，触发样本约占三分之二，说明在当前 APK、提示词和模型组合下，触发现象并非少数偶发事件，而是具有较高频率的实验结果。
图 2  全部有效测试中 P 与 F 的数量及比例。
2. 模型与 Prompt 的影响
模型 × Prompt 组合结果显示，Claude Sonnet 5 + Prompt B 的触发率最高，为 22/27（81.5%）；Claude Sonnet 5 + Prompt A 为 20/27（74.1%）。GPT-5.6 的两个组合明显较低，其中 Prompt B 为 6/15（40.0%），Prompt A 为 5/15（33.3%）。
图 3  四种模型 × Prompt 组合的经验触发率
结论1：表明定向功能描述可能提高模型对注入关联位置的关注度，从而增加触发概率。该效应方向在两个模型总体上保持一致，但其幅度远小于模型之间约 41 个百分点的差异。
结论2：在当前数据下，模型选择是决定触发行为的主要因素，Prompt 类型是次要但仍可观察到的因素。

5. 触发证据与行为类型
详细记录中的关键输出主要包括
“Chat paused”
“对话断开”
“提示高风险”
“发现文本注入”。
结论3：Claude Sonnet 5 的 P 结果常伴随“Chat paused”，而 GPT-5.6 的 P 结果多表现为“对话断开”。此外，GPT-5.6 还多次给出“提示高风险”或“发现文本注入”，但部分记录仍被标记为 F。
这说明当前 P/F 统计更接近对话层面的最终状态，而“识别目标功能 Y/N”反映的是内容理解或风险识别状态。举例而言，部分 GPT 记录虽然识别到文本注入或提示存在高风险，但并未按照 P 标准计为触发。

========== task3\task3实验报告.docx ==========
1. 结论
①实验一：模型选择会显著影响 B 类 SRT 触发结果，在完全相同的 12 个 B 类样本上，Terra、Claude、Grok 的触发率分别为 83.3%、75.0% 和 16.7%，模型差异在 Local 条件下更明显。
②实验二：SRT注入内容文本的类别对触发结果的差异不显著，当前数据不足以证明 SRT 类别具有稳定主效应。但六个 APK 的补充类别实验可证明C、B类触发率较高，R、N类较低。
③实验三：注入位置（global和local）对触发率存在明显描述性趋势，但触发率还受应用间异质性、注入点影响。
④实验四：我们的方法可较为稳定地触发claude和GPT5.6，模型及提示词选择的组合会显著影响重复触发表现。
⑤实验五：消融实验即通过无害化，证明无害化文本注入不会降低触发率。
2. 实验设计
实验材料由 6 个不同功能领域的 APK（Notes、Paint、Musicplayer、Clock、Filemanager、Voicerecorder）、4 类 SRT（C、B、R、N）、2 种注入位置（Local/Global）以及 3 个 Agent （Claude Code + Sonnet 5、GPT5.6 Terra、Codex + Grok ）组合构成。
未无害化组共有 48 个 APK；Notes 另提供 8 个无害化 APK 用于消融分析。
