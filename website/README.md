# SRT 研究网站

## 项目概述

本网站展示了 **Safety-Refusal Triggers (SRT)** 的研究成果——一种面向 LLM 辅助安卓逆向的主动防御机制。

## 网站结构

### 主要章节

1. **英雄区 (Hero)** - 核心概念介绍和关键数据展示
2. **背景动机 (Background)** - LLM 逆向威胁与传统保护方法的局限
3. **SRT 方法 (Method)** - 工作原理、无害化处理、注入方式
4. **实验材料 (Materials)** - 6款APK、4类SRT、3套Agent配置
5. **实验一 (Task1)** - 护栏行为画像（164条记录）
6. **实验二 (Task2)** - Agent端到端触发（84次测试）
7. **实验三 (Task3)** - 系统性因素分析（5组子实验，80条记录）
8. **核心发现 (Findings)** - 关键结论、局限性、未来方向
9. **团队引用 (Team)** - 研究团队信息与论文引用

### 实验数据总览

- **Task 1**: 164条护栏行为记录，100%触发率
- **Task 2**: 84次端到端测试，63.1%触发率
- **Task 3**: 80条系统性分析记录
  - E1: 模型差异测试（36次）
  - E2: 类别敏感性分析
  - E3: 注入位置对比（48次）
  - E4: Pass@3稳定性
  - E5: 无害化消融（24次）
- **主实验**: 72次测试，62.5%触发率

## 设计特点

### 视觉风格

- **深色主题**: 五层渐进式表面色阶 (#05070c → #1e2636)
- **色彩系统**: 
  - 主色调: 青色 (#38bdf8)、紫色 (#a78bfa)
  - CBRN分类色: C-琥珀、B-翠绿、R-粉红、N-蓝色
- **动画**: 滚动触发的渐显动画、数字计数动画、进度条动画
- **响应式**: 完整的移动端适配

### 数据可视化

- 横向条形图（触发率对比）
- 数字统计卡片（关键指标）
- 分类标签系统（CBRN四类）
- 表格展示（模型对比、应用列表）

### 交互体验

- 固定导航栏，自动高亮当前章节
- 平滑滚动锚点跳转
- Intersection Observer 驱动的滚动动画
- 悬停效果增强视觉反馈

## 技术实现

- **纯静态**: HTML + CSS + Vanilla JavaScript
- **无依赖**: 不依赖任何外部框架或库
- **轻量级**: 单文件约58KB，加载快速
- **可访问性**: 语义化HTML结构

## 如何使用

1. 直接在浏览器中打开 `index.html` 即可查看
2. 或使用本地服务器（推荐）:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # 或 Node.js
   npx serve
   ```
3. 访问 http://localhost:8000
